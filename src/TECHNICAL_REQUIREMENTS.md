# Technical Requirements

* The application must be implemented using TypeScript.
* The codebase must include automated tests for important game logic.
* The application must not rely on cloud resources.
* The application must run entirely within the browser.
* The game must be able to run locally using a standard development environment.
* Core gameplay must not require an internet connection after the application has been loaded.
* The source code should be structured so that game logic, rendering, input handling, and level data are reasonably separated.
