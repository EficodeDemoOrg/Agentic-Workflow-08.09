# Task 6 : Tying it Together

![06_Tying_It_Together](/exercises/images/06_Tying_It_Together.png)

At this point we have in our repository a workflow that prioritizes the open issues (Task 1), and we have a workflow that implements issues (Pre-existing).

Now we want to tie these together.

## Requirements

- [ ] Once everyday we select one issue based on priority to implement
- [ ] Start the [Plan and Implement](/.github/workflows/plan-implement.yml) workflow providing the number of the issue we chose it the previous step

Use the open issues on the repo to test out the workflow. If you run out of issues use the description-to-github-issues skill with a description of additional features to run.
