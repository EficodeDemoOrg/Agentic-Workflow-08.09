When creating C# code, these are the rules to adhere to:
1. **Naming Conventions**: Use PascalCase for class names and method names, camelCase for local variables and parameters, and UPPER_CASE for constants.
2. **Code Structure**: Organize code into namespaces and classes logically. Each class should be in its own file, and files should be named after the class they contain.
3. **Error Handling**: Use try-catch blocks to handle exceptions gracefully. Log errors for debugging purposes and provide meaningful error messages to the user.
4. **Comments and Documentation**: Write clear comments to explain complex logic. Use XML documentation comments for public methods and classes to generate API documentation.
5. **Code Readability**: Keep methods short and focused on a single task. Use descriptive names for methods and variables to enhance readability. Avoid deep nesting of code blocks.
6. **Testing**: Write unit tests for critical components of your code. Use a testing framework like NUnit or MSTest to ensure your code behaves as expected. Aim for high code coverage and test edge cases.
7. ** Performance Optimization**: Optimize code for performance where necessary. Avoid unnecessary computations and use efficient algorithms. Profile your code to identify bottlenecks.
